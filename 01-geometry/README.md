# 01 · Geometry

Making form: lofts from sections, gears, fasteners and springs, meshes.

| Tool | What it does |
| :-- | :-- |
| [slice-to-loft](slice-to-loft) | Section curves → lofts that don't twist, with fillets set by number |
| [gear-generator](gear-generator) | Involute spur gears and their mating racks, with true trochoid root fillets |
| [screws-nuts-springs](screws-nuts-springs) | Metric and inch screws, nuts, tapped holes and compression springs, with the holes to cut for them |
| [retopology](retopology) | An all-quad mesh from a network of edge curves |
