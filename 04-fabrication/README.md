# 04 · Fabrication

Getting it cut: outlines and pocket geometry for laser and CNC.

| Tool | What it does |
| :-- | :-- |
| [silhouette-outlines](silhouette-outlines) | Closed outer and inner outlines of solids seen along a plane, ready to cut |
| [pocket-dado-outlines](pocket-dado-outlines) | The pockets and dados in a solid part, as outlines grouped by depth, for CNC |

The exporter that turns geometry into Biesse CNC programs has its own repo: [biesse-gcode-exporter](https://github.com/ClipisHip/biesse-gcode-exporter).
